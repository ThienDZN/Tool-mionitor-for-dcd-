# Resource Folder

Bo tai lieu lien quan vao day de app uu tien tim kiem local truoc khi fallback sang web.

## Nen dung

- `.txt`
- `.md`
- `.pdf`
- `.docx`

## Goi y

- Dat ten file ro rang theo mon hoc hoac chu de.
- Tach tai lieu theo tung mon/tung chuong de tim nhanh hon.
- Sau khi them file trong luc app dang chay, mo tray menu va bam `Refresh resources`.
